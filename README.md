# ✂️ Cute Throw Showdown 🎀

🌸 An adorable Rock-Paper-Scissors game with pastel aesthetics and playful interactions!

## 🧸 Features
- 🍄 **Cute Emoji Battles**: Play with rock (🪨), paper (📜), scissors (✂️)
- 🍰 **Cookie Scoring**: Track wins with cookie emojis
- 🌸 **Pastel Visuals**: Soothing pink color scheme
- 🎀 **Playful Animations**: Bouncing buttons and emojis
- 🎮 **Mobile Optimized**: Perfect for quick games
